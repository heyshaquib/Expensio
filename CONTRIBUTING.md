# Contributing to Expensio

First off, thank you for considering contributing to Expensio! It's people like you that make open-source software such a great community to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for Expensio. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
- **Use the Bug Report Template:** When creating an issue, select the Bug Report template and fill out all the required information.
- **Check Existing Issues:** Before submitting a bug, please check if the issue has already been reported.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion, including completely new features and minor improvements.
- **Use the Feature Request Template:** When creating an issue, select the Feature Request template.
- **Provide Context:** Explain why this enhancement would be useful to most users.

### Code Contributions
Expensio is built entirely with **Flutter** and **Material Design 3**.

1. **Fork the Repo:** Click the Fork button in the top right corner of the repository.
2. **Clone your Fork:** `git clone https://github.com/heyshaquib/Expensio.git`
3. **Open in IDE:** Open the cloned directory in VS Code or Android Studio.
4. **Create a Branch:** Create a new branch for your feature or bugfix: `git checkout -b feature/your-feature-name`
5. **Commit your Changes:** Make your changes and commit them with descriptive commit messages.
6. **Push and Pull Request:** Push your branch to your fork and submit a Pull Request to the `main` branch of this repository.

## Development Setup
- The project requires Flutter SDK `^3.7.0`.
- Build the app using your IDE, or via command line with `flutter run`.

We look forward to your contributions!
